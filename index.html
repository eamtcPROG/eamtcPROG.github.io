Iftamaster

Trucking fleets file IFTA fuel-tax reports every quarter, usually by keying in fuel receipts and mileage records by hand. Iftamaster takes the uploaded documents and does that work: an asynchronous, queue-based pipeline sends each file through Google Document AI to extract the data, then Vertex AI Gemini to interpret it.
